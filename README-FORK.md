> 本仓库是 [JIZURA](https://github.com/852wa/JIZURA) 的个人修改版本，**不是原作者官方仓库**，也不代表原作者立场。

## 首先，感谢原作者

这个项目基于 **852wa** 的 [JIZURA](https://github.com/852wa/JIZURA)（MIT License）。

JIZURA 本身是一个非常出色的工具：输入歌词即可自动组合出文字 PV（歌词动态视频）的分镜，把排版、运动、装饰、转场、后期拆解成 **1,715 个可组合部件 + 27 种风格**，每次一键随机都能生成不同构成；同时支持浏览器直接使用、MP4 / PNG / 透明素材 / AE 工程数据导出，以及配套的 After Effects 面板。

感谢原作者以 MIT 协议开源，让个人可以在此基础上自由修改和扩展。原作者的版权声明与 `LICENSE` 文件在本仓库中原样保留。

如果你想使用原版，请前往：
- 官方仓库：<https://github.com/852wa/JIZURA>
- 官方在线版：<https://852wa.github.io/JIZURA/>

## 我做了哪些修改和增强

本分支在原版基础上，**保留了全部原版功能**，并新增了以下内容（基于 v0.13.0）：

### 一、AI 增强功能（原版政策不涉及，因此放在个人分支）

| 功能 | 说明 |
|---|---|
| **AI 语音识别歌词** | 接入 Whisper（faster-whisper），从音频自动转录歌词并生成时间轴，支持 SRT / LRC 输出，可选择模型、自动检测 GPU 加速 |
| **人声分离** | 集成 Demucs，可将歌曲中的人声与伴奏分离，再对干净人声做识别，提升准确率；首次使用自动安装依赖 |
| **在线歌词搜索** | 通过 lrclib.net 按歌曲名 / 歌手搜索现成歌词，快速导入 |
| **歌词自动对齐** | 将歌词按音频节拍自动对齐到分镜时间点，也支持手动打点（Tap）同步 |
| **SRT / LRC 导出** | 把识别结果或当前歌词导出为字幕文件 |

以上功能由随仓库附带的本地服务提供（`lyrics_tools/server.py`，默认监听 `127.0.0.1:8080`）。**歌词和音频只在你的本机处理，不会上传到任何第三方服务器**；只有在线搜词功能会向 lrclib 发起查询。双击 `启动AI版.bat` 即可一键启动本地服务并打开页面。

### 二、中文汉化与易用性

- 补全并修正简体中文 / 繁体中文界面的翻译
- 新增 AI 功能相关的中文界面文案
- 提供 `启动AI版.bat`、`更新JIZURA.bat`、`关闭服务.bat` 等一键脚本，方便日常使用与跟随原版更新

### 三、本次新增的编辑功能

| 功能 | 说明 |
|---|---|
| **镜头大字编辑框** | 位于下方「一键随机」右侧，显示当前镜头的显示文字；修改后按新文字生成画面，**不影响左侧歌词原文，也不改变分镜与时间点** |
| **内容锁定** | 位于上方「一键随机」右侧；勾选后点一键随机，只改变风格 / 氛围 / 配色，**分镜、时间和你改过的文字全部保持不变**；不勾选时则和原版一样全部重新生成 |

### 四、与原版保持同步

- 已合并官方 v0.13.0 的全部更新（含「追加分 2」的 855 个新部件、SRT/VTT 导入、越南语修正、各类 bug 修复等）。新部件默认关闭，可在「手法」页签中开启「使用新增特效 2」后使用。

## 使用方式

1. 双击 `启动AI版.bat`，脚本会启动本地服务并打开 `http://127.0.0.1:8080/zh-hans/`。
2. 也可以直接用浏览器打开 `zh-hans/index.html` 使用**不含 AI 功能**的纯前端部分（功能与原版一致）。
3. 需要 AI 识别 / 人声分离时，请确保本地服务正在运行。
