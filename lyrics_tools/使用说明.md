# 🎵 JIZURA 歌词识别工具

用 **Whisper** AI 模型自动从音乐中识别歌词，生成带时间戳的字幕文件，然后导入 JIZURA。

---

## 🚀 快速开始

### 第一步：安装依赖（只需一次）

双击运行 **`安装依赖.bat`**

> 会自动下载安装 faster-whisper 库。首次使用还会下载模型文件（small 模型约 466MB）。

### 第二步：识别歌词

**方式 A：拖拽（推荐）**
- 把音乐文件直接拖到 **`识别歌词.bat`** 上
- 等待识别完成...
- 会在音乐同目录生成 3 个文件：
  - `歌曲名.srt` — SRT 字幕（带时间，导入 JIZURA 用这个）
  - `歌曲名.lrc` — LRC 歌词（带时间）
  - `歌曲名_歌词.txt` — 纯文本歌词

**方式 B：双击运行**
- 双击 **`识别歌词.bat`**
- 按提示输入文件路径、选择模型和语言

### 第三步：导入 JIZURA

1. 打开 JIZURA 简体中文版
2. 点 **「导入字幕」** 按钮
3. 选择生成的 `.srt` 文件
4. 完成！歌词和时间全部导入 ✨

## 📊 模型选择

| 模型 | 大小 | 速度 | 准确率 | 推荐场景 |
|---|---|---|---|---|
| `tiny` | ~75MB | 极快 | ⭐⭐ | 快速预览、说话内容 |
| `base` | ~145MB | 快 | ⭐⭐⭐ | 语速慢的歌曲 |
| **`small`** | ~466MB | 中等 | ⭐⭐⭐⭐ | **日常推荐，均衡之选** |
| `medium` | ~1.5GB | 慢 | ⭐⭐⭐⭐⭐ | 日语/韩语歌，追求准确 |
| `large-v3` | ~3GB | 很慢 | ⭐⭐⭐⭐⭐+ | 最高精度，复杂歌曲 |

> 💡 有 NVIDIA 显卡的话速度会快很多（GPU 加速）

## ⚙️ 高级用法（命令行）

```bash
# 基本用法
python transcribe_lyrics.py 歌曲.mp3

# 指定模型和语言
python transcribe_lyrics.py 歌曲.mp3 --model medium --language zh

# 日语歌 + 大模型
python transcribe_lyrics.py 日本語歌.mp3 --model large-v3 --language ja

# 禁用 VAD（有时 VAD 会漏掉轻声歌词）
python transcribe_lyrics.py 歌曲.mp3 --no-vad

# 指定输出目录
python transcribe_lyrics.py 歌曲.mp3 -o ./output
```

## 💡 提高识别准确率的技巧

1. **先用人声分离工具处理**（如 UVR5）
   - 把伴奏去掉，只留人声 → 识别准确率大幅提升
   - 处理完再用本工具识别人声文件

2. **选择合适的模型**
   - 中文歌 → small 以上
   - 日语/韩语歌 → medium 以上
   - 对准确率不满意就换大一号的模型

3. **指定语言**
   - 确定是什么语言就指定，比自动检测更准

4. **识别后校对**
   - 打开生成的 `.srt` 文件检查一下
   - 有错别字直接改，时间戳不用动
   - 然后再导入 JIZURA

## ❓ 常见问题

**Q: 提示找不到 python？**
A: 说明你电脑没装 Python。去 https://www.python.org/downloads/ 下载安装，安装时记得勾 "Add Python to PATH"。

**Q: 模型下载太慢？**
A: 首次使用需要下载模型。可以挂代理，或者手动下载放到 `C:\Users\你的用户名\.cache\huggingface\` 目录。

**Q: 识别出来全是错字？**
A: 试试更大的模型，或者先用人声分离工具去掉伴奏。

**Q: 只有 CPU 能用吗？**
A: 可以，就是慢一些。一首歌 small 模型 CPU 大概需要 3-5 分钟。

**Q: 怎么在 JIZURA 里用？**
A: 打开 JIZURA → 点「导入字幕」→ 选 .srt 文件 → 歌词和时间一次性导入。
