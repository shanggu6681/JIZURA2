# JIZURA 字面 — 文字 PV 自动构成工具

> [!IMPORTANT]
> **这是个人修改分支，不是原作者官方仓库，也不代表原作者立场。**
> 本分支基于原作者 [852wa/JIZURA](https://github.com/852wa/JIZURA)（MIT License），在保留原版全部功能的基础上，新增了 AI 歌词识别、人声分离、在线搜词、自动对齐、中文汉化，以及镜头大字编辑、内容锁定等功能。
> 详见下方「[本分支的改动](#本分支的改动)」。原版请见 <https://github.com/852wa/JIZURA>。

输入歌词，就能自动组合出文字 PV（歌词动态视频）中常见的表现手法，生成分镜并导出 MP4。把排版、运动、装饰、转场、后期拆解成 **1,715 个微小部件（外加 27 种风格）**，每次随机组合都不同——换一个种子就能得到完全不同的构成。同时附带 After Effects 面板（脚本版，以及可直接使用浏览器版界面的 CEP 版）。

**版本：v0.13.0**（更新记录见 [CHANGELOG.md](CHANGELOG.md)）

- 无需安装。歌词、歌曲、导出全部在浏览器内处理，不会发送到服务器（唯一从外部读取的是 Google Fonts 字体，且只加载当前构成用到的书体）。
- 「一键随机」按钮（快捷键 `R`）每按一次，风格、氛围、运动、配色、构成都会整体改变。
- 播放位置所在的行，可按 `D` 重新抽取、按 `L` 切换锁定（可用「上一个方案」回退）。
- 画面比例 16:9 / 9:16 / 4:3 / 3:4 / 1:1 / 4:5 / 21:9，720p～4K，24 / 30 / 60fps。
- 载入歌曲后会自动检测节拍并对齐分镜，也支持手动打点同步。
- 支持导出 MP4（含歌曲）、序列 PNG、透明 PNG。可把背景设为**绿幕 / 黑幕**（只保留白色文字和特效）作为合成素材导出，也能导出可供 After Effects 编辑的构成数据（JSON）。

> 注：原作者的项目方针是不实现需要外部服务器/服务的功能，以及 AI 相关功能。本分支的 AI 功能属于个人分支扩展，**未提交给原仓库**，详见下方「[开发方针](#开发方针)」。

## 本分支的改动

在官方 v0.13.0 基础上，本分支保留原版全部功能，并新增以下内容：

### AI 增强功能（原版方针不涵盖，仅在个人分支提供）

| 功能 | 说明 |
|---|---|
| **AI 语音识别歌词** | 接入 Whisper（faster-whisper），从音频自动转录歌词并生成时间轴，支持 SRT / LRC 输出，可选模型、自动检测 GPU 加速 |
| **人声分离** | 集成 Demucs，可把歌曲中的人声与伴奏分离，再对干净人声做识别以提升准确率；首次使用自动安装依赖 |
| **在线歌词搜索** | 通过 lrclib.net 按歌曲名 / 歌手搜索现成歌词并导入 |
| **歌词自动对齐** | 把歌词按音频节拍自动对齐到分镜时间点，也支持手动打点（Tap）同步 |
| **字幕导出** | 把识别结果或当前歌词导出为 SRT / LRC 字幕文件 |

以上功能由随仓库附带的本地服务提供（`lyrics_tools/server.py`，默认监听 `127.0.0.1:8080`）。歌词和音频只在你的本机处理，**不会上传到任何第三方服务器**；只有在线搜词会向 lrclib 发起查询。

### 中文汉化与易用性

- 补全并修正简体中文 / 繁体中文界面翻译，新增 AI 功能相关的中文界面文案。
- 提供 `启动AI版.bat`、`更新JIZURA.bat`、`关闭服务.bat` 一键脚本，方便日常使用与跟随原版更新。

### 本次新增的编辑功能

| 功能 | 说明 |
|---|---|
| **镜头大字编辑框** | 位于下方「一键随机」右侧，显示当前镜头的显示文字；修改后按新文字生成画面，**不影响左侧歌词原文，也不改变分镜与时间点** |
| **内容锁定** | 位于上方「一键随机」右侧；勾选后点一键随机，只改变风格 / 氛围 / 配色，**分镜、时间和改过的文字全部保持不变**；不勾选时则和原版一样全部重新生成 |
| **片头 / 尾音 / 片尾常驻模块** | 「行与镜头」列表顶部常驻 **OP（片头）**、**尾（尾音）**、**ED（片尾）** 三行，各自独立设置起止时间、文字与布局；**时间为 0 即不生成**，控件始终显示。尾音模块在入场动画播完后**定格**（背景、相机、文字、特效全部静止）。片头有「⏎ 首行」一键读取第一行歌词的开始时间；**尾音和 ED 有「⏎ 末尾」一键读取音频总时长**（自动填入最后 6 秒区间，未载音频时用歌词总长）。三行都常驻一个「布局」下拉（可选择「吊挂」等布局：有镜头时逐镜头设置，无镜头时预设模块默认布局，二者互斥不会重复） |
| **三个模块拥有完整镜头功能** | OP / 尾音 / ED 与普通歌词行完全一样：可打开「手法」面板逐镜头挑模板（布局 / 登场 / 保持 / 退场 / 装饰 / 加工 / 背景 / 相机 / 衔接），可用 ＋ / × 增删镜头、逐个镜头调布局与开始时间、播放到该镜头时自动展开手法面板并用大字框改这一镜的显示文字 |
| **间奏式倒计时叠加（本模块新增）** | 每个特殊模块都有「间奏倒计时」勾选和尺寸滑块：勾选后**保留所选模板与文字**，只叠加一个剩余秒数倒计时（和歌词里的 `[間奏]` 一样）；滑块只能在原始尺寸范围内**调小**，不会放大 |
| **倒计时起始坐标** | 尺寸滑块右侧新增横 / 纵两个坐标输入框（百分比，**50 / 50 = 画面正中**）。改这两个数即可把倒计时放到画面任意位置，例如 `20 , 80` 放到左下、`0 , 0` 放到左上角；超出 0～100 会自动夹回边界 |
| **时间与文字框布局调整** | 特殊模块的起止时间框改为与普通行等宽；模块文字输入框缩短，长文字改在下方镜头大字框里编辑；修复了模块下方说明文字被挤成竖排、以及布局下拉框重复出现两个的问题（现在每行只有一个「模板选择」下拉） |

右上可切换「简单 / 详细」界面。默认以简单模式打开（手机上为「手机」模式，见下方「手机模式」）。

- **一键生成**（键盘 `R` 也可以）：每按一次，会重新随机决定以下内容，并从头播放。
  - 风格（不会连续出现相同的）
  - 氛围（故障 / 静谧 / 流行 / 图形 / 编辑风 / 情感 / 全部混合。开启「也使用恐怖特效」时还会包含恐怖）。不同氛围下，运动强度、故障量、使用的布局和登场 / 退场手法都会变化。
  - 标题和衬线框的书体
  - 配色（有时会连同强调色与错位色 A/B 一起随机）
  - 分镜构成（种子）
- **◀ 上一个方案 / 下一个方案 ▶**：在随机出的方案之间来回切换，可回到喜欢的方案再导出。
- **只改变这里**：保留当前方案，只重新抽取其中一部分。
  - 风格 / 配色（强调色、错位色 A/B）/ 氛围（运动和使用的手法）/ 构成（布局与运动的组合）
- 歌词、歌曲、时间点和导出设置不会被一键随机改变。用钥匙锁定的行也会原样保留。

<details>
<summary><h2>浏览器版使用方法</h2></summary>

1. **歌词**：一行就是一个短语。记法如下。
   - `夜明けの色を/覚えてる` … 用 `/` 指定分镜的切分点
   - `*透明*` … 强调（更容易选中放大、有冲击力的特效）
   - 行末的 `!` … 加入闪光和抖动
   - `歌词|注释` … 显示在注释布局里的小字
   - `[01:23.45]歌词` … 可直接使用 LRC 时间戳。没有时刻的行会按书写位置插入前后时刻之间
   - 歌词框右上角「读取 LRC / SRT」可把 .lrc 或字幕文件（.srt / .vtt）作为歌词读入（替换当前歌词，可用「撤销」恢复）。字幕一个块为一行，块结束时刻到下一块开始相隔 1 秒以上的地方会变成 `[间奏]`
   - 歌曲、歌词（.lrc / .srt / .vtt / .txt）、工程（.json）也可以拖放到画面上读入
   - `[间奏 8]` … 8 秒间奏。不显示歌词，只播放背景、装饰和画面特效（6 秒以上会小字显示曲名和歌手）。省略秒数则为 4 秒，可用打点同步或标记调整长度。`[interlude]` `[间奏]` `[간주]` 同样有效
2. **歌曲与时间点**
   - 载入歌曲后会自动检测 BPM 和节拍，把分镜切分点对齐到节拍。载入的歌曲会保存在这个浏览器中，重新打开页面时自动再次载入（避免导出时漏掉音频）。
   - 按「打点同步」后歌曲开始播放。在每一行开始的瞬间按空格键。按错了用 Backspace 或「后退一个」。点行列表的 ◎ 可**从该行重新打点**（前面的时刻保留）。
     - 打点时可用「速度」降到 0.75× / 0.5× 来听（保存的时刻仍是歌曲原本的时刻）。开启「倒计时」会在 3、2、1 之后开始播放。
     - 一行有多个分镜时，在分镜切换的瞬间按 Tab，也能对齐该行分镜的开始时刻。
   - 也可以直接改写行列表里的秒数。与前后行顺序颠倒的值会被修正到不颠倒的位置。
   - **分镜开始时刻**（详细模式）：行下方每个分镜的栏里，会显示第二个及之后分镜的开始时刻。填入数值即固定，清空则恢复自动。播放中的分镜会加框标示。
   - **时间轴**：左右拖动上方的刻度（行分隔线）可改变该行的开始时刻（吸附节拍，按 Shift 自由移动）。＋／− 和滚轮缩放，Shift＋滚轮左右移动，「全体」复位。
   - 歌词、时间点的改动可用「撤销」（Ctrl+Z）取消。
3. **逐行修改**（简单模式下也可用）
   - ✎（或双击歌词）可就地修改该行歌词，记法同样可用。
   - 「分镜 自动 / 1～6」决定把该行分成几个分镜。
   - 每行的骰子可只重新抽取该行。用钥匙固定该行的构成，也可直接指定布局（详细模式）。上锁的行即使对别的行点骰子、随机或一键随机，其布局、运动、装饰、配色、分镜都原样保留。
   - 「随机编排」可重新抽取整体。
   - **主题**：一键随机按钮旁（简单模式下在下方）的「主题」可选文字 PV / 动态 / 和风 / 恐怖 / 流行 / 抒情，在该方向内进行一键随机。所需的部件开关（文字 PV 系、动态、和风与追加分、恐怖）会被开启。「无主题」则和以往一样。
   - **逐分镜替换**（详细模式）：点击预览下方的分镜信息（布局、登场、保持、退场、装饰、加工、背景、镜头、转场）会打开列表，可只替换该分镜为别的部件。选「自动」恢复原样。行列表中也会出现逐分镜选择布局的栏。「重新抽取／一键随机此分镜」可只重新选择该分镜。替换不会影响其他分镜的抽取结果。
   - **镜头大字编辑框**（本分支新增，详细模式）：在下方「一键随机」右侧，显示当前分镜的大字文字。改完后画面按新文字生成，不影响歌词原文和分镜时间点。
   - **内容锁定**（本分支新增）：在上方「一键随机」右侧。勾选后点一键随机，分镜、时间点、改过的文字都保持不变，只换风格 / 氛围 / 配色。
   - **锁定**（详细模式）：「手法」页签各分类的钥匙可保持该分类的 ON/OFF 选择方式，「特效」页签的滑块、闪光、抽帧的钥匙可保持其值，一键随机后也不变。锁定会保存到工程文件。
   - **循环**：播放按钮旁的「循环」每按一次在 全体 → 行 → 分镜 → 无 之间切换。行 / 分镜循环时，时间轴会显示重复范围。
4. **风格**：有 27 套配色、书体、质感组合（樱花 / 深海 / 夕阳渐变 / 森林手帖 / 蒸汽波 / 报纸 / 合成器 80s / 牛皮纸 / 糖果 / 酸性 / 墨与朱 / 金夜，以及恐怖用的 废墟 / 深夜录像 / 诅咒信件 等）。同一支视频里，不同分镜也会切换背景色。
   - 书体从 Google Fonts 的 18 个字族中选取（含 Reggae One / Rampart One / Potta One / Kiwi Maru / Klee One / Shippori Mincho B1）。**只加载当前构成用到的书体**，所以书体数量增加也不会拖慢启动和运行。
   - 字体可用以下方式替换：
     - 输入电脑上已安装的字体名
     - 读取 .ttf / .otf 文件
5. **特效与手法**
   - 「特效」页签可调整运动强度、故障、色差、装饰量、分镜细度、质感、抽帧。
   - 「隐藏装饰数字」「隐藏装饰时刻」可关闭布局、装饰、HUD 附加的 `No.01`、`00:12.34` 之类文字（歌词本身包含的数字、时刻照常显示）。
   - 「手法」页签可对 10 个分类（布局、登场、保持、退场、装饰、文字加工、背景、镜头、画面特效、分镜间转场）逐个部件 ON/OFF（与上面的「追加分」「和风」勾选组合判定）。各分类可折叠，支持「全部 ON / 全部 OFF / 反转」和按名称筛选。
6. **导出**
   - MP4（Chrome / Edge 为 H.264，可含歌曲）
   - 序列 PNG（ZIP）
   - 透明 PNG（ZIP，无背景，供 AE 等合成使用）
   - 序列 PNG、透明 PNG 也可从简单模式的导出中选择。
   - 歌词（LRC）：导出带各行开始时刻的 .lrc。选择了导出范围时，只导出该范围的行，且时刻以视频开头为基准。
   - 「背景」选**绿幕 / 黑幕**可得到只有白字和特效的合成素材（详见下方「合成用背景」）。
   - 画面比例 16:9 / 9:16 / 4:3 / 3:4 / 1:1 / 4:5 / 21:9，分辨率 720p～4K，帧率 24 / 30 / 60fps 可选（详见下方「24 / 30 / 60fps 导出」）。
   - **只导出选中的行**：在「导出范围」选第一行和最后一行，或点行列表的 ⇥（Shift＋点击可扩大范围）。文件名会带 `_L03-05` 这样的行号。
   - **不易导出失败**：采用逐段写入的方式，长歌曲或 1080p / 1440p 也不会一次性占用大量内存。GPU 编码器失败时会自动切换到软件编码器重新导出。
   - **大视频用（直接保存到文件）**：Chrome / Edge 中可先选择保存位置，再直接写入该位置。适合长歌曲高分辨率导出。
   - 音频：当浏览器无法用 AAC 导出（变成 Opus 或无法导出音频）时，iPhone 或 QuickTime 可能没有声音，因此会同时保存一份等长的 WAV 音频。
   - **字幕导出**（本分支新增）：可将识别结果或当前歌词导出为 SRT / LRC 字幕文件。
- **统一感**（「特效」页签 / 简单模式的勾选）：开启后按文字 PV 的定式来组合。
  - 每个段落（用空行分隔的组）统一布局、运动、镜头、装饰。重复的歌词（如副歌）会以和第一次相同的呈现方式回归。
  - 运动方向交替（左→右、上→下），强烈的运动留给关键的行。
  - **高潮（キメ）**：行末带 `!` 的行（没有则取重复段落的开头行）用一个分镜大胆呈现（大字、闪光、缩放、抖动）。
  - **形变（モーフ）**：同一行切换到下一个分镜时，相同的字移动，其余的字溶化变化。
  - **字重**：有时会呈现从细字逐渐变粗的效果（Noto Sans / Serif JP 可变字体）。
- **文字排版**（同一位置的勾选）：收紧假名字距让文字成块阅读，助词（は・が・を・に 等）缩小、行首字放大、英文稍微放大并与日文之间留一点空隙。文字比声音提前 0.2 秒出现，避免特效叠加过多（装饰最多 1 个，画面特效每个分镜最多 1 个）。
  - 两种排法都保留了传统组合方式，取消勾选即可恢复原样。AE 面板中会带入选中的布局、运动和时刻（字距、字号调整、字重、morph 在 AE 中是近似表现）。
- **中央留白（用于角色）**：「导出」设置里的勾选。假设要在中央叠加角色等，把歌词分成两部分，横屏放在左右、竖屏放在上下两条带（例：「花が」｜「咲いた」。带在横屏约为宽度的 36%、21:9 为 30%，竖屏为高度的 33%）。左右（上下）使用相同布局、运动、装饰、镜头的同一个场景，后半部分稍微延迟出现。背景和画面特效保持全屏，不使用把歌词大字画在背景上的背景（巨大文字）。只有一个词的短行会在两侧显示相同的词。竖屏时可在「竖屏时」选择上下分开还是左右分开（左右时带为宽度的 34%）。预览中用虚线显示留白范围（不写入导出）。AE 面板（脚本版「从歌词」、CEP 版、JSON）也是同样的配置。
- **画面固定显示**：宽高足够的屏幕下，整个页面不滚动，中央的预览和时间轴始终可见。歌词 / 行列表（左）和设置（右）在各自的列内滚动。播放时行列表自动跟随当前行（刚手动滚动过列表时会暂停跟随）。窄屏时仍和以前一样整页滚动。
- **清空歌词 / 初始化**：「清空歌词」（歌词框右上）会清除歌词和逐行时间点、指定、导出范围，可用「撤销」或 Ctrl+Z 恢复。页首「初始化」会清除歌词、歌曲（含浏览器中残留的）、设置、方案历史和撤销历史，回到初始状态（确认后执行，无法撤销）。显示模式、音量、界面语言会保留。

7. **导出为 AE 用**：把当前构成（时间点、布局、特效、配色）导出为 JSON。用 AE 面板读入后，会生成保持相同构成、可继续编辑的合成。

<summary><h3>24 / 30 / 60fps 导出</h3></summary>

1. 在「导出」页签（简单模式下在右侧「导出」栏）选择画面比例、分辨率和 **fps**。
2. 按「导出 MP4」。会按所选 fps 的帧数原样导出（例：6 秒在 24fps 为 144 帧，60fps 为 360 帧）。
3. 运动的卡顿程度由「特效」页签的 **抽帧** 单独决定，与 fps 无关。
   - **2 帧抽帧（12 张/秒）**：文字 PV 特有的略带卡顿的运动。无论用哪个 fps 导出，观感相同（默认）。
   - **3 帧抽帧（8 张/秒）**：更有作画感、偏定格的运动。
   - **全帧**：按输出 fps 每帧都动。60fps + 全帧最流畅（镜头运动和流动带更顺滑）。
4. 故障和闪烁的随机切换，在改变 fps 时仍以 24fps 为基准保持相同速度。用 60fps 导出也不会让闪烁变成两倍速。
5. 参考：YouTube / MV 用 24fps（或 30fps），想让 SNS 竖屏视频更流畅用 30～60fps + 全帧。60fps・4K 导出较耗时。

AE 面板中，面板的「fps」（24 / 30 / 60）可选择合成的帧率。从 JSON 生成时，会得到浏览器版所选 fps 的合成。

</details>

<details>
<summary><h3>合成用背景（绿幕 / 黑幕）</h3></summary>

想在实拍或插画画面上只叠加歌词时使用。

1. 在「导出」页签（简单模式下在右侧「导出」栏）的 **背景** 中选以下之一。
   - **通常**：保持风格的配色和背景（默认）
   - **绿幕**：在 `#00FF00` 上只保留白字和特效
   - **黑幕**：在 `#000000` 上只保留白字和特效
2. 预览会原样反映（右上角显示「绿幕」等）。无论用 MP4、序列 PNG 还是透明 PNG 导出，观感相同，文件名末尾带 `_greenback` / `_blackback`。
3. 合成方法
   - 绿幕：用视频编辑软件的色键（Premiere Pro 的 Ultra 键、DaVinci Resolve 的 3D Keyer、AE 的 Keylight 等）抠掉绿色。
   - 黑幕：把混合模式设为 **屏幕**（或相加）叠加，或用亮度键抠掉黑色。
   - 用透明 PNG 导出可得到一开始背景就透明的白色素材。

**透明 PNG 前景／后景（ZIP）** 会把每一帧的 2 张透明 PNG 输出到 zip 内的不同文件夹。
   - `back/`：后景（背景图形和歌词后方的装饰）
   - `front/`：前景（歌词、其周围的装饰和边框、色差残影、HUD）
   - 全屏特效（闪光、画面分割等）会同样作用于两者，把 `front` 叠在 `back` 上即可还原通常观感（不含背景色、纸张质感、发光、扫描线）。

透明 PNG 中，全屏特效（反转、闪光、频闪、色相偏移、画面分割、上下滑动、显像管关闭、黑帧等）也不会填满背景，只作用于文字和装饰部分（黑帧 / 白帧会成为空的透明帧）。

- 文字、装饰、特效全部变为白～灰的单色。不含风格配色、背景花纹、纸张质感、粒子、暗角（构成、运动、特效的组合与「通常」时相同）。
- 色差残影和光晕用灰色绘制，抠键后会变成半透明。绿幕按「把黑幕用屏幕模式叠加时」的效果制作。
- 闪光、反转、频闪等全屏特效会原样保留为白光。不需要时可在「特效」页签关闭闪光或减弱故障，或在「手法」页签的「画面特效」中单独关闭。
- AE 面板也可在面板的「背景」选同样设置。「导出为 AE 用」的 JSON 中也包含背景设置。

</details>

<summary><h2>After Effects 面板使用方法</h2></summary>

AE 面板有两种，内部的生成引擎相同。

- **脚本版（`JIZURA_AE.jsx`）**：AE 的脚本面板。可从歌词生成，也可读入浏览器版的 JSON。
- **CEP 版（`JIZURA_CEP.zip`）**：可在 AE 内直接使用浏览器版界面和预览的面板。按「在 AE 中生成合成」即可就地生成合成（见下方「CEP 版」）。

<details>
<summary><h3>安装方法</h3></summary>

1. 把 `JIZURA_AE.jsx` 放到以下文件夹，然后重启 AE。
   - Windows：`C:\Program Files\Adobe\Adobe After Effects <版本>\Support Files\Scripts\ScriptUI Panels\`
   - Mac：`/Applications/Adobe After Effects <版本>/Scripts/ScriptUI Panels/`
2. 从菜单「窗口」→「JIZURA_AE.jsx」打开面板，可停靠。
3. 只是试用的话，也可用「文件 → 脚本 → 运行脚本文件」（会成为浮动窗口）。

</details>

<details>
<summary><h3>使用方法</h3></summary>

- **从歌词生成**：决定歌词、风格、尺寸、特效后，按「生成合成」。
  - 时间点可从以下 3 种中选择。
    - 自动（按字数、BPM 计算）
    - 所选图层的标记
    - 合成标记
  - 推荐流程：选中歌曲图层，边播放边用小键盘 `*` 在每行开头打标记，选「用所选图层的标记作为行首」再生成。
- **一键随机生成**：每按一次，随机决定风格、氛围、特效强度、2 帧抽帧 / 闪光 / HUD、种子、配色，并反映到面板显示，生成新的合成。喜欢结果的话，可从那里调整数值再按「生成合成」重做。
- **氛围**（「特效」栏）：选择后会限定符合该氛围的布局、登场、退场手法来组合。具体限定哪些手法由种子决定，所以相同种子得到相同结果。
- **强调色·错位色**：用「随机配色」重新选择强调色和错位色 A/B。也可按 `#RRGGBB` 格式直接输入。勾选「覆盖风格颜色」会应用到生成合成的所有场景（亮度会根据背景自动补正）。
- **追加分·和风·部件集·背景**：与浏览器版相同的「也使用追加特效」「也使用和风特效」「使用文字 PV 系部件」「使用动态部件」「也使用恐怖特效」勾选，以及「背景」（通常 / 绿幕 / 黑幕）可选。27 种风格全部可选（列表中的〔追加〕〔和〕〔ホ〕是标记）。恐怖开启时氛围会加入「恐怖」。
- **支持的部件**：浏览器版全部 1,715 个部件（布局 364・登场 251・保持 102・退场 221・装饰 260・文字加工 122・背景 130・镜头 71・画面特效 138・分镜间转场 56。v0.9.0 加入文字 PV 系、动态、恐怖的 153 个部件，v0.13.0 加入追加分 2 的 855 个部件），用 AE 的文字图层、形状图层、蒙版、特效、表达式组合。歌词在任何部件中都保持为文字图层，之后可改字。
  - 追加分 2 的部件是在模拟 AE 的环境中确认的，尚未在真实 AE 中验证。若与浏览器版在外观或运动上有差异，请通过 Issue 告知。
  - 以词为单位运动的动态部件，在 AE 中用逐词文字图层（或同一文字图层的逐字动画器）组合。对齐歌曲节拍的部分，在 AE 中按均分分镜长度来运动。
  - 3D 旋转、纸张翻页运动、逐像素加工（像素排序、抖动等），用 AE 标准特效和 2D 变形替换为近似外观。
  - 若 JSON 中含有面板不认识的部件名（如今后浏览器版新增的部件），会替换为最接近的部件组合，并在面板下方状态显示「有替换」。
- **尺寸**：1920×1080 / 1080×1920 / 1080×1080 / 3840×2160 / 1280×720 / 1440×1080（4:3）/ 1080×1440（3:4），或与当前合成相同。
- **从 JSON**：读入浏览器版「导出为 AE 用」生成的 JSON。浏览器中决定的构成会原样在 AE 中组合。
- **字体**
  - 若安装了 Noto Sans JP / Noto Serif JP / Dela Gothic One 等会自动使用（自动选择需要 AE 2024 以上）。
  - 未安装时使用「字体」页签指定的书体，默认为游 Gothic・游 Mincho。

- **轻量**（减轻 AE 播放负担）：省去色差复制、纸张质感、辉光、粒子、复制插画的画面特效，图层数约减少 4 成，长歌曲在 AE 中播放也更轻快。
- **长歌曲**：合成会分段逐步生成，生成过程中 After Effects 不会「无响应」。面板会显示进度（百分比・分镜数），按 **中止** 会用已完成的分镜收尾合成（脚本版、CEP 版相同）。撤销会被细分，重做时请在项目面板删除合成和 `cuts` 文件夹。

- **诊断报告**（「从 JSON」页签）：让 AE 计算最后生成合成的表达式，把错误和替换汇总保存到 `JIZURA_report.txt`。效果不如预期时，请附上该文件报告。

</details>

<summary><h3>CEP 版（在 AE 中使用浏览器版界面）</h3></summary>

1. 下载并解压 [`JIZURA_CEP.zip`](https://852wa.github.io/JIZURA/JIZURA_CEP.zip)。
2. Windows 运行 `install_win.bat`，Mac 运行 `install_mac.command`（复制到用户的 CEP 扩展文件夹，并设置为可加载未签名面板）。
3. 重启 After Effects（2022 以上），打开 **窗口 → 扩展 → JIZURA 字面**。

- 歌词、风格、特效的决定方式与浏览器版相同。按 **在 AE 中生成合成** 即可就地生成当前构成的合成。
- 用 **导出范围** 选好行后，只生成这些行的合成（歌曲也对齐到相同位置）。适合把长歌曲分几次生成。「导出为 AE 用」的 JSON 也是相同范围。
- **AE 中选中的歌曲**：在 AE 中选中歌曲图层后再按，会解析该歌曲并对齐节拍，合成中也会放入该歌曲。
- **用 AE 的标记作为行首**：把所选图层（没有则用合成）的标记作为各行的开始时刻。
- 也可从面板直接导出 MP4、序列 PNG（保存位置通过对话框选择）。
- 详细安装方法和签名版 `.zxp` 的制作方法见 zip 内的 `README_CEP.md`。

</details>

<details>
<summary><h3>生成的内容</h3></summary>

- 每个分镜的预合成（`JIZURA <曲名> cuts` 文件夹）
  - 某些部件会在分镜内进一步生成预合成（如 `JZ … art`）或色差用副本（`… ghost`：去掉纸张、板等背景物的版本）。
- 生成结束时，会删除所有未使用的隐藏图层。剩余的隐藏图层只有轨道遮罩（按 AE 的规则，用作遮罩的图层本身不显示）。
  - 文字通过文字动画器（表达式选择器）运动，所以改字后运动仍会保留。
- 色差通过把每个分镜延时复制，并用「色调」特效着色的残影图层来表现。
- 最上层的 `JZ FX` 调整图层汇总了以下内容。
  - 2 帧抽帧（ posterize time）
  - 抖动（变换）
  - 切片故障（波形变形）
  - 缩放模糊 / 反相 / 辉光 / 噪点
- 还会生成 `JZ Flash`、`JZ Vignette` 和 HUD（时间码、行计数器）。
- 背景设为绿幕 / 黑幕时，最上层会用 `JZ Key Mono`（用色调单色化的调整图层）代替 `JZ Vignette`，绿幕还会额外加入 `JZ Key Green`（混合模式：屏幕）。

</details>

<summary><h3>注意事项</h3></summary>

- 假设表达式引擎为 JavaScript（AE 2020 以上新建项目的默认值）。
- 本面板在模拟 AE 对象模型的环境中验证。已确认 707 个部件各自在多种字数、画面比例下组合无错误，全风格 × 多种种子的一键随机生成无错误，并与浏览器版相同构成比对过外观和运动一致性。但尚未在真实 AE 中运行。若特效设置等出现意外情况，生成后会列出该项目并继续生成其他部分。
- 部件多的分镜会有较多图层和表达式。长歌曲的生成和预览可能较耗时（把预览分辨率降到 1/2～1/4 会轻快些）。

## 开发方针

JIZURA 遵循以下两条方针。符合其中任一条的功能原则上不实现（收到 Pull Request 也可能不采纳）。

**1. JIZURA 自身不与外部收发数据**：仅靠放在 GitHub Pages 上的单个页面运行，不把歌词或歌曲传出浏览器。

- 需要与外部服务器或服务收发数据的功能（API 调用、账户 / 登录、云保存、分析 / 追踪等）
- 运行时从外部 CDN 或模型分发源读取程序或数据的功能
- 唯一的例外是按需从 Google Fonts 读取当前构成使用的书体。

**2. 不加入与 AI 联动的功能**：包括不对外通信的在内。

- 用 LLM 决定演出、用语音识别转录歌词 / 对齐时间、面向 AI 代理的操作接口（WebMCP 等）

不过，让使用者自己的 AI 工具打开并阅读 JIZURA 页面，不属于 JIZURA 的功能，而是使用者的判断。想使用上述功能的人，可以自由地 fork 后公开（MIT License）。欢迎修复缺陷、添加表现部件，以及提出 / 提交可在浏览器内完成的功能。

> **本分支说明**：本分支正是依据上述 MIT 授权进行的 fork。AI 相关功能只存在于本分支中，**未向原仓库提交 Pull Request**；原版仍遵循其方针。感谢原作者允许自由 fork。
